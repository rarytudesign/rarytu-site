Connect GitHub

The site lives in a GitHub repository, so this computer needs a GitHub access token once. It stays in this browser only.

  1. Open github.com → new fine-grained token.
  2. Name: “rarytu backups”. Expiration: 1 year. Repository access: Only select repositories → rarytu-site.
  3. Permissions → Repository permissions → Contents: Read and write. Generate the token and copy it.

Site backups

A backup is a ZIP with the whole site: every page in both languages, styles, scripts, fonts, images, videos and CVs. It is saved to your computer only. Restoring puts the whole site back exactly as it was in the backup.
